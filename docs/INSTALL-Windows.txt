PaySprout 薪芽

适用：Windows 10/11 x64。自带 .NET 10 运行时，无需另行安装。

完整解压 ZIP 到固定目录，双击 PaySprout.exe 启动。请勿在压缩包内直接运行。
首版为免安装应用，不创建系统启动项；退出后可以删除应用目录。

首版未做商业代码签名，Windows SmartScreen 可能提示未知发布者。
请核对下载来源和 SHA-256；确认后可在系统提供的「更多信息」中选择「仍要运行」。
组织管理的电脑可能不允许此操作；请遵循管理员要求。

顶部设置按钮（Ctrl+,）修改日薪与上下班时间。Enter 保存，Esc 取消。
AA 调整大小，拖动右下角也可调整。紧凑模式的 … 提供更多操作。
减号收起到系统托盘，双击托盘薪芽图标恢复；× 退出。
设置保存在 %LOCALAPPDATA%\PaySprout\settings.json。
v0.1.1 起支持应用内更新：托盘 / 设置中选择「检查更新…」，下载后点击「重启更新」。
更新保留薪资和窗口设置，临时充电计时随重启结束。解压目录必须有写入权限。
v0.1.0 用户需先手动安装一次带更新器的新版。
本工具仅作陪伴与收入估算，不代表实际结算工资。

源代码与更新：https://github.com/xyq20/PaySprout
