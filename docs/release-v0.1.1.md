# PaySprout · 薪芽 v0.1.1

新增 macOS / Windows 双端应用内更新。

- 启动后自动检查最新稳定版本，也可在菜单栏 / 托盘、设置页和紧凑模式更多菜单中点击「检查更新…」。
- 应用内下载更新、显示下载进度、支持取消；校验完成后点击「重启更新」。
- 校验更新包 SHA-256、大小、版本与目录结构，失败时保留旧版。新版未完成启动确认时自动恢复旧版。
- 更新保留薪资、班次与窗口设置；临时充电计时随重启结束。

**已经安装 v0.1.0 的用户，需要手动下载并安装这次更新，之后才能使用应用内更新。** 本功能更新原生应用，需要重启生效。

下载 macOS 通用 DMG / ZIP（macOS 26+，Apple Silicon 与 Intel），或 Windows x64 免安装 ZIP（Windows 10/11，自带 .NET 10 运行时）。应用目录需要有写入权限，不能在只读 DMG 中直接更新。

首版沿用本地签名 / 未商业签名方式，尚无 Apple 开发者公证与 Windows 商业代码签名。首次安装可能出现系统提示，详见安装包内说明。附件附带 SHA256SUMS.txt。

验证包括双端业务模型、版本与元数据边界、下载完整性 / 摘要 / 取消 / HTTP 错误 / 归档路径检查，以及隔离目录中的真实更新替换与失败回滚。Windows 使用云端发布 EXE 完成启动确认测试；未覆盖所有用户设备与企业权限策略。
