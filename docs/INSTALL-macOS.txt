PaySprout 薪芽

适用：macOS 26 或更新版本；Apple Silicon 和 Intel。

打开 DMG，将「上班鼓励器.app」拖入 Applications，然后从应用程序启动。
ZIP 用户请先解压，再将应用移至 Applications。

首版采用本地临时签名，尚未通过 Apple 开发者公证。
若 macOS 阻止首次启动，请在「系统设置 → 隐私与安全性」中核对来源，
然后选择「仍要打开」。菜单项由系统版本与安全策略决定。
组织管理的电脑可能不允许此操作；请遵循管理员要求。

在「更多 → 偏好设置」填写日薪与上下班时间。减号收起到菜单栏太阳图标，× 退出。
v0.1.1 起支持应用内更新：菜单栏 / 设置中选择「检查更新…」，下载后点击「重启更新」。
更新保留薪资和窗口设置，临时充电计时随重启结束。更新目录必须有写入权限。
v0.1.0 用户需先手动安装一次带更新器的新版。
本工具仅作陪伴与收入估算，不代表实际结算工资。

源代码与更新：https://github.com/xyq20/PaySprout
